# Plush Gray

Hyperrealistic standing silver tabby painted on HTML Canvas 2D.

Open `cat-art/index.html` via a local server (canvas loads `assets/tabby-standing.png` for the portrait underpainting, then applies canvas coat strokes, lighting, vignette, and grain).

```bash
cd cat-art && python3 -m http.server 8765
# → http://127.0.0.1:8765/
```
